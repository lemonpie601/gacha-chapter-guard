# Gacha Chapter Guard

Gacha Forge **1.8.13**용 서버 런타임 패치. Node **24** 권장.

## 기능

- 기기별로 잘못 저장된 챕터 번호를 연속된 일반 난이도 진행 기록으로 보정합니다.
- 앞 챕터가 없거나 미완료이면 서버가 뒤 챕터 요청을 거절하고 클라이언트를 앞 챕터로 돌려보냅니다.
- 마지막 챕터를 완료했다는 이유만으로 재접속 시 다음 챕터 번호를 올리지 않습니다.
- 적 이미지 생성 요청은 **너비 384 × 높이 576**으로 보냅니다. 일반 캐릭터·의상·배경 크기는 변경하지 않습니다.

기존 챕터·진행도·이미지는 삭제하지 않습니다. 이미 생성된 뒤 챕터는 앞 구간을 완료한 뒤 다시 열 수 있습니다. 기존 적 이미지는 캐시를 유지하므로 크기는 새로 생성되는 이미지부터 적용됩니다. 이미지 제공자가 요청 크기를 강제 변경하는 경우 최종 파일 크기는 달라질 수 있습니다.

## 설치

브라우저의 확장 가져오기용 패키지가 아닙니다. **Marinara가 실행되는 PC에 한 번 설치**하면 같은 서버에 접속하는 iPad/Tailscale에도 적용됩니다.

1. 저장소 ZIP을 내려받아 풉니다.
2. `install.cmd` 실행. 기본 경로는 `%LOCALAPPDATA%\Marinara-Engine`입니다.
3. 진행 중인 생성 작업이 끝난 뒤 Marinara를 평소 방식으로 종료·재실행합니다.
4. PC와 iPad 페이지를 새로고침합니다.

다른 설치 경로:

```powershell
node manage.cjs install "C:/your/Marinara-Engine"
```

설치기는 테스트 후 패치 파일을 엔진 폴더에 복사하고 `.env`의 기존 `NODE_OPTIONS`에 `--require` 항목을 추가합니다. 다른 패치 항목은 유지하며 `.env`와 기존 동명 패치를 백업합니다. 서버를 자동 종료하거나 재시작하지 않습니다. 설치 경로에 공백이 있으면 설치기는 중단합니다.

## 제거

`remove.cmd` 실행 후 서버 재시작 및 브라우저 새로고침. 시작 옵션에서 이 패치만 제거합니다. 패치 파일과 백업은 남깁니다.

## 검증·제한

```powershell
node test.cjs "C:/your/Marinara-Engine"
```

실제 1.8.13 코드의 메모리 변환, 불연속 진행도 복원, 서버 생성 차단, 적·일반 캐릭터의 이미지 요청 크기를 모의 테스트합니다. 테스트는 이미지 API를 호출하거나 게임 데이터를 변경하지 않습니다.

엔진/가챠 포지 업데이트로 코드 서명이 바뀌면 변환을 건너뛰며 보호가 적용되지 않을 수 있습니다. 서버 로그의 `[chapter-guard]` 적용/불일치 메시지를 확인하세요. 기존에 시작된 생성 요청은 취소하지 않습니다. 설치 후 실제 iPad 재접속 시험은 별도로 필요합니다.

패키지 원본을 수정하지 않고 Node 모듈 로드 시 메모리에서 적용합니다. 챕터 진행을 직접 편집한 세계에도 순서 검사가 적용됩니다.
